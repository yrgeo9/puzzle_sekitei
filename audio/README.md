# 音源の差し替え

今の音は、すべてブラウザの中で合成して鳴らしています。録音した音源に差し替えるときは、次の2つを行います。

1. 音源ファイルを、この `audio` フォルダに置く。
2. `sounds.json` で、差し替えたい音の欄にファイル名を書く。

```json
"bgm": "bgm.mp3",
"place": "ishi.mp3",
```

`null` のままの音は、合成した音が鳴り続けます。1つだけ差し替えることもできます。

## 音の一覧

| 名前 | 鳴る場面 | 長さの目安 |
|---|---|---|
| `bgm` | ずっと流れる背景音楽（繰り返し再生） | 1〜3分。始まりと終わりが自然につながるもの |
| `place` | 石を置いた | 0.1〜0.3秒 |
| `remove` | 石を取った | 0.1〜0.2秒 |
| `mark` | 「石なし」の印を付けた | 0.1秒前後 |
| `unmark` | 印を消した | 0.1秒前後 |
| `undo` | 一手戻した | 0.2秒前後 |
| `hint` | 「ひとつ教えて」で一手示した | 0.5〜1.5秒 |
| `error` | 置いた石が決まりに反した（隣り合う など） | 0.2秒前後 |
| `clear` | 解けた | 1〜3秒 |
| `new` | 新しい庭を始めた・ならし直した | 0.5〜1.5秒 |
| `tap` | メニューやボタンを押した | 0.05秒前後 |

## ファイルの決まり

- 形式：**mp3 がおすすめ**です（iPhone を含むすべての主要ブラウザで再生できます）。ほかに m4a / aac / ogg / wav も指定できますが、ogg は古い iPhone では鳴りません。
- ファイル名：半角の英数字・`-`・`_`・`.`・空白だけを使い、80文字以内にしてください。フォルダ名を含む指定（`../` など）は無視されます。
- 音量：合成音と同じくらいの大きさにそろえると、全体のバランスが保てます。BGM は控えめに作っておくのがおすすめです。
- 効果音は、無音の部分を前後に残さないでください。押したときの反応が遅れて聞こえます。
- 公開するのは、配布してよい許可がある音源だけにしてください（自作、または再配布が認められたフリー素材など）。
