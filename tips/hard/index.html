解き方のコツ（六間・八間・難しい）

六間・八間の「難しい」の庭で使う形です。1つの行・列・苔だけでは次の一手が決まらないとき、2つの手がかりの置き方の組み合わせを全部考え、どの組み合わせでも同じになるマスを確定します。組み合わせる手がかりの種類ごとに並べています。

行（列）と行（列）

隣り合う2つの行（列）を組み合わせる形です。

どの置き方でも隣になるマスは空き

例1

→

三の行の石は4三か3三。どちらに置いても隣になる4二・3二・4四・3四は空き。苔の候補でも同じ考え方が使えます。

例2

→

二の行の石は2二か1二。2三・1三はどちらとも隣り合うので、三の行の石は6三。

どの2×2にも、石は1つまで

→

三の行の残り1つの石は4三か3三で、どちらも枠の2×2の中。2×2の4マスはお互いに隣り合うので石は1つまで。だから四の行の残り1つの石は、枠の外の1四。

苔のまわりや隣り合う2行・2列を2×2に区切ると、入る石の上限が数えられる。

行（列）と苔

片方の石が必ずもう片方の中に入るなら、もう片方の残りの石はそのぶん減り、0になればほかの候補は空きになります。

石がどちらかに入る2マスが同じ行（列）にあれば、その行（列）のほかのマスは空き

六間・八間では、1つの行に石は1つだけ。だから「この行の石は、このマスかあのマスのどちらか」と分かれば、その行のほかのマスには石が入らない。列でも同じ。2マスのどちらに入るかまで分からなくても、ほかのマスは空きと決められる。

例1　苔「1」の候補が同じ行に2マス

→

6五の苔「1」のまわりで石を置けるのは6六と5六だけ。どちらも六の行なので、六の行の石は6六か5六。六の行のほかの3六・2六・1六は空き。

例2　辺の苔「2」

→

4二はほかの4マスすべてと隣り合うので空き（苔の「2」で片側の3マスが使えない形）。残る候補は、5の列の5一・5二と、3の列の3一・3二。

列で見ると：同じ列の2マスは隣り合うので、石は1つまで。「2」なので5の列から1つ、3の列から1つ入る。5の列の石は5一か5二なので、5三〜5六は空き。3の列も同じで、3三〜3六は空き。

行で見ると：5一と3一、5二と3二はそれぞれ同じ行なので、2つ同時には入らない。「2」なので一の行から1つ、二の行から1つ入る。一の行の石は5一か3一なので、6一・2一・1一は空き。二の行も同じで、6二・2二・1二は空き。

苔と2つの行（列）をまとめて見るので、「難しい」の中では少し手数の多い形。辺の苔「2」でよく出るので、形ごと覚えておくと便利。

苔の候補を、行ごと・列ごとに分けて数えてみると見つかりやすい。

行の候補が苔のまわりに収まれば、苔の残りは空き

→

一の行の候補は6一か5一で、どちらも5二の苔「1」のまわり。「1」は一の行の石で埋まるので、6二・4二・6三・5三・4三は空き。

はみ出した候補が互いに隣り合えば、行に必ず1つ入る

→

4二の苔「2」の候補は、一の行の5一・4一・3一と、はみ出した3二・4三・3三（枠）の3行・3列。枠の3マスは互いに隣り合うので、石は1つまで。もう1つは必ず一の行に入るので、6一・2一・1一は空き。

角の苔「1」は、横2・縦1と横1・縦2離れたマスが空き

→

4二に石があると、苔の石は6二しか残らず、二の行に石が2つ並ぶ（5三も同じく5の列で並ぶ）。苔から横に2つ・縦に1つ（または横に1つ・縦に2つ）離れた2マスは空き。

苔と苔

重なり合う2つの苔を組み合わせる形です。

小さい苔の候補が大きい苔のまわりに収まれば、引き算で残りが決まる

→

6三の苔「1」の候補（6二・5二・6四・5四）は、すべて5三の苔「2」のまわり。「2」の1つはここで埋まるので、残り1つは4二。

灯籠と行（列）

「灯籠あり」の庭で、灯籠と行（列）を組み合わせる形です。

横の光が行の端から端まで届くなら、縦の光が空きになることがある

→

行の石は必ず光の中にあり、横の光だけで1つ数える。灯籠の数が「1」なら、縦の光は空き。

行・列の石が1つの庭で「2」なら、光の外は空き

→

石は行に1つ・列に1つ。「2」ならどちらも光の中なので、5三・3一は空き。
