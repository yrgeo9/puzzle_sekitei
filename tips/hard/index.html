解き方のコツ（難しい）

「難しい」の盤面は、1つの行・列・苔石だけを見ても次の一手が決まらない場面があります。2つの手がかり（行と行、行と苔石、苔石と苔石）の置き方の組み合わせを全部考え、どの組み合わせでも同じになるマスを確定するのが基本です。候補が2〜3マスしかない行・列・苔石を探し、隣の行や重なる苔石と組み合わせてみてください。砂紋をこまめに付けると候補が見えやすくなります。図の多くは実際の盤面から取っています。

片方の石が、もう片方の中に必ず入る六間八間十間

例1

→

6五の苔石「1」の石は六の行（6六か5六）に入るので、3六・2六・1六は空き。

例2

→

一の行の候補は6一か5一で、どちらも5二の苔石「1」のまわり。「1」は一の行の石で埋まるので、6二・4二・6三・5三・4三は空き。

例3

→

6三の苔石「1」の候補（6二・5二・6四・5四）は、すべて5三の苔石「2」のまわり。「2」の1つはここで埋まるので、残り1つは4二。

例4

→

4二の苔石「2」の候補は、一の行の5一・4一・3一と、はみ出した3二・4三・3三（枠）の3行・3列。枠の3マスは互いに隣り合うので、石は1つまで。もう1つは必ず一の行に入るので、6一・2一・1一は空き。

片方の石が必ずもう片方の中に入るなら、もう片方の残りの石はそのぶん減り、0になればほかの候補は空き。候補がはみ出していても、はみ出したマスに石が1つしか入らなければ使える（例4）。

どの置き方でも隣になるマスは空き六間八間十間

例1

→

三の行の石は4三か3三。どちらに置いても隣になる4二・3二・4四・3四は空き。苔石の候補でも同じ考え方が使えます。

例2

→

二の行の石は2二か1二。2三・1三はどちらとも隣り合うので、三の行の石は6三。

例3

→

三の行は残り2つで、候補は7三〜4三の4マス続き。隣り合わない置き方は「7三と5三」「7三と4三」「6三と4三」の3通りで、どれも7三・6三のどちらかに1つ、5三・4三のどちらかに1つ石が入る。だから、その上下の7二〜4二と7四〜4四は空き。

どの2×2にも、石は1つまで六間八間十間

例1

→

三の行の残り1つの石は4三か3三で、どちらも枠の2×2の中。2×2の4マスはお互いに隣り合うので石は1つまで。だから四の行の残り1つの石は、枠の外の1四。

苔石のまわりや隣り合う2行・2列を2×2に区切ると、入る石の上限が数えられる。

例2

→

8・7の列には石が2つずつ、計4つ。2×2には石が1つまでなので、全部砂紋の三〜四を除く4つのかたまりに1つずつ入る。五〜六は候補が8六だけなので、8六は石。

角の苔石「1」は、横2・縦1と横1・縦2離れたマスが空き六間八間
→

4二に石があると、苔石の石は6二しか残らず、二の行に石が2つ並ぶ（5三も同じく5の列で並ぶ）。苔石から横に2つ・縦に1つ（または横に1つ・縦に2つ）離れた2マスは空き。

苔石の数が「入れられる最大数」と等しいなら、余裕なく入る六間八間

例1

→

石は「5一と3二」か「3一と5二」。どちらでも一・二の行と5・3の列を使い切るので、その残りと4二・4三は空き。

例2

→

三の行はもう1三で揃っているので、5三の苔石「2」のまわりに入れられる石は、二の行から1つと四の行から1つの最大2つ。これが苔石の数と同じなので、どちらの行も石を苔石のまわりに入れるしかなく、二・四の行の残りは空き。

苔石のまわりに入れられる石の最大数を、行・列の残りや「2×2には1つまで」から数える。苔石の数と同じなら、置き場所が決まる。

いくつかの行が、同じ数の列を取り合う六間八間

例1

→

二と四の行の候補は、どちらも2か1の列。2行の石2つで2・1の列を使い切る（赤い列）ので、ほかの行の2・1の列は空き。

例2

→

一・三・五の行の候補は、どれも6・4・2の列の中。3つの行の石3つで6・4・2の列を使い切る（赤い列）ので、二・四・六の行の6・4・2の列は空き。

行の候補が、行と同じ数の列に収まっていたら、その列はその行で使い切られる。行と列を入れ替えても同じ。

「難しい」を学ぶ
