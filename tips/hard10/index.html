解き方のコツ（十間・難しい）

十間の「難しい」の庭で使う形です。1つの行・列・苔だけでは次の一手が決まらないとき、2つの手がかりの置き方の組み合わせを全部考え、どの組み合わせでも同じになるマスを確定します。組み合わせる手がかりの種類ごとに並べています。十間では行・列に石が2つずつ入るので、行の候補の並び方からも、隣の行や苔のまわりが決まります。

行（列）と行（列）

隣り合う2つの行（列）を組み合わせる形です。

どの置き方でも隣になるマスは空き

→

三の行は残り2つで、候補は7三〜4三の4マス続き。隣り合わない置き方は「7三と5三」「7三と4三」「6三と4三」の3通りで、どれも7三・6三のどちらかに1つ、5三・4三のどちらかに1つ石が入る。だから、その上下の7二〜4二と7四〜4四は空き。

どの2×2にも、石は1つまで

→

8・7の列には石が2つずつ、計4つ。2×2には石が1つまでなので、全部砂紋の三〜四を除く4つのかたまりに1つずつ入る。五〜六は候補が8六だけなので、8六は石。

候補が5マス幅に収まる行は、2番目と4番目の上下が空き

→

三の行は残り2つで、候補は8三〜4三の5マス続き。8三〜6三に1つも入らないと、残りの5三・4三に2つ入って隣り合ってしまう。だから8三〜6三に必ず1つ、同じように6三〜4三にも必ず1つ入る。8三〜6三のどれにも隣り合う7二・7四と、6三〜4三のどれにも隣り合う5二・5四は、空き。

候補が「8三・6三〜4三」や「8三・6三・4三」のように飛び飛びでも、5マス幅に収まっていれば同じ。

片方に1つしか入らないなら、もう片方に必ず1つ

→

三の行は残り2つ。3三には1つしか入らないので、9三〜7三に必ず1つ入る。3マスのどれにも隣り合う8二・8四は空き。

行（列）と苔

片方の石が必ずもう片方の中に入るなら、もう片方の残りの石はそのぶん減り、0になればほかの候補は空きになります。

苔の「3」から2つ離れた上下左右のマスは空き

→

「隅3つ」では、隅の石はそれぞれ2つの辺にまたがるので、3つで上・下・左・右のすべての辺に石が入る。「辺の真ん中1つ＋反対側の隅2つ」でも、真ん中の石がその辺に、隅2つが残りの3辺に入る。どちらの置き方でも各辺（3マス）に石があり、苔から2つ離れた5三・7五・3五・5七は辺の3マスすべてと隣り合うので、空き。

「3」の置き方は、「普通・苔」の「苔の「3」の置き方は2種類」を参照。苔と、2つ離れたマスを通る行（列）を組み合わせて考える形です。

必ず1つ入るマスが苔「1」のまわりに収まれば、苔の残りは空き

→

二の行の候補は8二〜4二の5マス続きなので、8二〜6二に必ず1つ入る（5マス幅の形）。この3マスは7三の苔のまわりに収まるので、苔の「1」はそれで使い切る。苔のまわりの残り、8三・6三・8四・7四・6四は空き（5三も5マス幅の形で空き）。

4マス続きの端、2マス続きの組、「3マス続き＋離れた候補」の真ん中のマスの隣にある苔「1」でも同じ。5マス続きの真ん中の隣にある苔では決まらない。

4マス続きの2番目の隣に苔「1」なら、反対の端が石

→

二の行の置き方は「8二と6二」「8二と5二」「7二と5二」の3通り。「8二と6二」は苔のまわりに2つ入るので使えない。残る2通りはどちらも5二が石、6二は空き。どちらでも苔のまわりに1つ入るので、苔のまわりの残りも空き。

苔と苔

重なり合う2つの苔を組み合わせる形です。

小さい苔の候補が大きい苔のまわりに収まれば、引き算で残りが決まる

→

6三の苔「1」の候補（6二・5二・6四・5四）は、すべて5三の苔「2」のまわり。「2」の1つはここで埋まるので、残り1つは4二。

灯籠と行（列）

「灯籠あり」の庭で、灯籠と行（列）を組み合わせる形です。

横の光が行の端から端まで届くなら、縦の光が空きになることがある

→

行の石は必ず光の中にあり、横の光だけで2つ数える。灯籠の数が「2」なら、縦の光は空き（「3」なら縦の光に1つ入る）。
