解き方のコツ（六間・八間）

「普通」の六間・八間の庭は、ここにあるコツだけで最後まで解けます。どれも、1つの苔か、1つの行（列）だけを見て決まる形です。

苔

苔の数字と、そのまわりの8マスから決まる形です。

苔の候補の数が苔の数と同じなら、候補はすべて石

→

4三の苔「2」のまわりで石を置けるのは、5二と3四の2マスだけ。数と同じなので、5二・3四はどちらも石。

苔のまわりの候補が、苔の数と同じだけしか残っていなければ、候補はすべて石。「1」や「3」でも同じ。苔「2」では、まず候補がいくつ残っているかを数えてみる。

苔の候補が互いに隣り合うなら、そこに入る石は1つまで

例1　2マス続き

→

5二・4二は2マス続きなので、石は1つまで。「2」のもう1つは3四。

例2　斜めの2マス

→

4二・3三は斜めに隣り合うので、石は1つまで。「2」のもう1つは5四。

例3　L字の3マス

→

3三・4四・3四は互いに隣り合うので、石は1つまで。もう1つは5二。

苔のまわりの候補に、互いに隣り合うマス（2マス続き、斜めの2マス、L字の3マス）があれば、そこに入る石は1つまで。苔の数に足りない分は、ほかの候補に入る。

苔の「2」で片側の3マスが使えないなら、向かいの真ん中は空き

例1　盤の端

→

一の行は盤の端なので、苔のまわりは5マスだけ。4二はほかの4マスすべてと隣り合うので、4二に石を置くと2つ目が置けない。4二は空き。

例2　揃った行

→

二の行はもう石が揃っていて、苔の上の3マスは使えない。残りは例1と同じ5マスの形になるので、4四は空き。

使えるマスが「横の2マス＋向かいの3マス」だけになると、向かいの真ん中はほかの4マスすべてと隣り合う。そこに石を置くと2つ目が置けないので、空きになる。
