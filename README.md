# 石庭ぱずる

庭に石を置いていくパズルゲームです。3つの決まりごとを守りながら、石をすべて置ききれば完成です。ブラウザだけで動き、インストールは不要です。スマホではホーム画面に追加すると、オフラインでも遊べます。

## 決まりごと

1. どの行にも、どの列にも、石を決まった数だけ置く。置く数は、盤の端の○の数で示される。
2. 石のまわりに石は置かれない。
3. 苔石に書いてある数は、まわりにある石の数。苔石は石として数えない。

追加の決まりごと（灯籠ありの庭）：灯籠に書いてある数は、光の中にある石の数。光は上下左右へまっすぐ伸び、苔石や灯籠で止まる。

盤面はその場で作られます。答えがひとつだけで、当てずっぽうや仮置きなしに推理だけで解けることを確かめてから出題します。

## つくり

- `index.html` 1枚で動く静的サイトです。サーバー側の処理はありません。

### 盤面・成績の保存先

- 途中の盤面と記録は、遊んでいる端末のブラウザ（localStorage）にだけ保存され、外部には送られません。

### 外部との通信

- 書体：Google Fonts から読み込みます。
- アクセス解析：公式サイト（puzzle-sekitei.jp）で開いたときだけ、Google アナリティクス 4 を読み込み、利用状況を Google に送ります。ほかの場所（ほかのドメインや手元のファイル）で開いたときは読み込みません。
- 広告：Google AdSense の掲載を準備中です。現在は広告を表示しておらず、広告用のスクリプトも読み込みません。
- 送信される情報と目的は、サイト内の[プライバシーポリシー](https://puzzle-sekitei.jp/privacy/)に記載しています。

### セキュリティ

- Content-Security-Policy で、ページに埋め込んだスクリプト（ハッシュで指定）と、そこから読み込む Google アナリティクスのスクリプト以外は実行できないようにしています。通信先も、自サイト・Google Fonts・Google アナリティクスに限っています。
- 他サイトの枠内への表示の禁止、HTTPS の強制などのレスポンスヘッダーを `_headers` で指定しています。
