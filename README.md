# パズル石庭

苔の数字を手がかりに、盤面に石を据える論理パズルです。ブラウザだけで動き、インストールは不要です。スマホではホーム画面に追加すると、オフラインでも遊べます。

## 決まりごと

1. どの行にも、どの列にも、石を決まった数ずつ置く（八間は1つ、十間は2つ）。
2. 石どうしは縦・横・斜めのどれでも隣り合わない。
3. 苔の上の数は、まわり8マスにある石の数。苔の上には石を置けない。

盤面はその場で作られます。答えがひとつだけで、当てずっぽうや仮置きなしに推理だけで解けることを確かめてから出題します。

## つくり

- `index.html` 1枚で動く静的サイトです。サーバー側の処理や外部への送信はありません。
- 途中の盤面と記録は、遊んでいる端末のブラウザ（localStorage）にだけ保存されます。
- 外部から読み込むのは Google Fonts の書体だけです。
- Content-Security-Policy で、ページに埋め込んだスクリプト以外は実行できないようにしています。
