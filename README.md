# 石庭ぱずる

庭に石を置いていくパズルゲームです。3つの決まりごとを守りながら、石をすべて置ききれば完成です。ブラウザだけで動き、インストールは不要です。スマホではホーム画面に追加すると、オフラインでも遊べます。

## 決まりごと

1. どの行にも、どの列にも、石を決まった数だけ置く。置く数は、盤の端の○の数で示される。
2. 石のまわりに石は置かれない。
3. 苔石に書いてある数は、まわりにある石の数。苔石は石として数えない。

追加の決まりごと（灯籠ありの庭）：灯籠に書いてある数は、光の中にある石の数。光は上下左右へまっすぐ伸び、苔石や灯籠で止まる。

盤面はその場で作られます。答えがひとつだけで、当てずっぽうや仮置きなしに推理だけで解けることを確かめてから出題します。

## つくり

- `index.html` 1枚で動く静的サイトです。サーバー側の処理や外部への送信はありません。
- 途中の盤面と記録は、遊んでいる端末のブラウザ（localStorage）にだけ保存されます。
- 外部から読み込むのは Google Fonts の書体だけです。
- Content-Security-Policy で、ページに埋め込んだスクリプト以外は実行できないようにしています。
