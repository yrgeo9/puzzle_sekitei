解き方のコツ

    解き方のコツ（基本）

    どちらの盤面でも使う、1つの行・列・苔だけを見れば決まる形です。「普通」の盤面は、この形だけで最後まで解けます。図は、形だけを取り出した簡単な例です。

    石のまわり8マスには、石を置けない六間八間十間

    揃った行・列・苔の残りは空き六間八間十間

    行・列の石が揃ったら、その行・列の残りのマスに砂紋を引く。苔の数だけ石が入ったら、苔のまわりの残りのマスに砂紋を引く。

    残りのマスの数＝残りの石の数なら、全部石六間八間十間

    例1

    例2

    →

    行・列でも苔のまわりでも、置けるマスが残りの石の数しかなければ、そのマスはすべて石。

    互いに隣り合うマスには、石は1つまで六間八間十間

    例1

    →

    3三・4四・3四は互いに隣り合うので、石は1つまで。もう1つは5二。

    例2

    →

    2マス続き（9三・8三）には石が1つまで。もう1つは3三。

    互いに隣り合うマス（2マス続き、L字の3マス、2×2など）には石が1つしか入らない。そこで足りない分は、ほかの候補に入る。

    苔の「4」は、四隅に石十間
    →

    隣り合わずに4つ置けるのは、四隅だけ。

    候補が3マス続きなら、両端に石十間
    →

    隣り合わずに石2つが入るのは、両端（8三・6三）だけ。

    苔の「3」の置き方は2種類十間

    例1

    →

    置き方は「隅3つ」か「辺の真ん中1つ＋反対側の隅2つ」。5三が空きなら、どれも3五を使う。

    例2

    →

    置き方は「隅3つ」か「辺の真ん中1つ＋反対側の隅2つ」。どれでも上下左右の各辺に石が入るので、2つ離れた4マスは空き。

    十間の苔「3」の置き方は「隅3つ」か「辺の真ん中1つ＋反対側の隅2つ」だけ。どちらの形になるかを考えると、決まるマスが見つかる。

    解き方のコツ（灯籠あり）

    「灯籠あり」の庭で使う考え方です。灯籠の光は上・下・左・右へまっすぐ伸び、苔・ほかの灯籠・盤の端で止まります。この光の中のマスを「照らすマス」と呼びます。灯籠をタップすると、照らすマスが光ります。

    灯籠「0」は、照らすマスがすべて空き六間八間十間
    →

    光は苔・灯籠・盤の端で止まる（苔の先の1三は照らさない）。照らすマスはすべて空き。

    照らすマスの数＝灯籠の数なら、全部石六間八間十間
    →

    4方向とも苔で止まり、照らすのは3二・3四だけ。どちらも石。

    横の光が行の端から端まで届くなら、縦の光が空きになることがある六間八間十間

    六間・八間の灯籠「1」

    →

    十間の灯籠「2」

    →

    行の石は必ず光の中にあり、横の光だけで六間・八間なら1つ、十間なら2つ数える。灯籠の数がそれと同じなら、縦の光は空き（十間の「3」なら縦の光に1つ入る）。

    行・列の石が1つの庭で「2」なら、光の外は空き六間八間
    →

    石は行に1つ・列に1つ。「2」ならどちらも光の中なので、5三・3一は空き。

    灯籠の縦の隣と横の隣は、同時に石にならない六間八間
    →

    横の光に石は1つまでなので、上の隣3二は石。縦の隣と横の隣は斜めに隣り合うので4三・2三は空きになり、横の石は1三。

    石20の庭では、灯籠の数は多くて4（行・列に2つずつ）。苔のまわりと光が重なるマスは、両方の数に関わります。

    解き方のコツ（難しい）

    「難しい」の盤面は、1つの行・列・苔だけを見ても次の一手が決まらない場面があります。2つの手がかり（行と行、行と苔、苔と苔）の置き方の組み合わせを全部考え、どの組み合わせでも同じになるマスを確定するのが基本です。候補が2〜3マスしかない行・列・苔を探し、隣の行や重なる苔と組み合わせてみてください。砂紋をこまめに付けると候補が見えやすくなります。図の多くは実際の盤面から取っています。

    片方の石が、もう片方の中に必ず入る六間八間十間

    例1

    →

    6五の苔「1」の石は六の行（6六か5六）に入るので、3六・2六・1六は空き。

    例2

    →

    一の行の候補は6一か5一で、どちらも5二の苔「1」のまわり。「1」は一の行の石で埋まるので、6二・4二・6三・5三・4三は空き。

    例3

    →

    6三の苔「1」の候補（6二・5二・6四・5四）は、すべて5三の苔「2」のまわり。「2」の1つはここで埋まるので、残り1つは4二。

    例4

    →

    4二の苔「2」の候補は、一の行の5一・4一・3一と、はみ出した3二・4三・3三（枠）の3行・3列。枠の3マスは互いに隣り合うので、石は1つまで。もう1つは必ず一の行に入るので、6一・2一・1一は空き。

    片方の石が必ずもう片方の中に入るなら、もう片方の残りの石はそのぶん減り、0になればほかの候補は空き。候補がはみ出していても、はみ出したマスに石が1つしか入らなければ使える（例4）。

    どの置き方でも隣になるマスは空き六間八間十間

    例1

    →

    三の行の石は4三か3三。どちらに置いても隣になる4二・3二・4四・3四は空き。苔の候補でも同じ考え方が使えます。

    例2

    →

    二の行の石は2二か1二。2三・1三はどちらとも隣り合うので、三の行の石は6三。

    例3

    →

    三の行は残り2つで、候補は7三〜4三の4マス続き。隣り合わない置き方は「7三と5三」「7三と4三」「6三と4三」の3通りで、どれも7三・6三のどちらかに1つ、5三・4三のどちらかに1つ石が入る。だから、その上下の7二〜4二と7四〜4四は空き。

    どの2×2にも、石は1つまで六間八間十間

    例1

    →

    三の行の残り1つの石は4三か3三で、どちらも枠の2×2の中。2×2の4マスはお互いに隣り合うので石は1つまで。だから四の行の残り1つの石は、枠の外の1四。

    苔のまわりや隣り合う2行・2列を2×2に区切ると、入る石の上限が数えられる。

    例2

    →

    8・7の列には石が2つずつ、計4つ。2×2には石が1つまでなので、全部砂紋の三〜四を除く4つのかたまりに1つずつ入る。五〜六は候補が8六だけなので、8六は石。

    角の苔「1」は、横2・縦1と横1・縦2離れたマスが空き六間八間
    →

    4二に石があると、苔の石は6二しか残らず、二の行に石が2つ並ぶ（5三も同じく5の列で並ぶ）。苔から横に2つ・縦に1つ（または横に1つ・縦に2つ）離れた2マスは空き。

    苔の数が「入れられる最大数」と等しいなら、余裕なく入る六間八間

    例1

    →

    石は「5一と3二」か「3一と5二」。どちらでも一・二の行と5・3の列を使い切るので、その残りと4二・4三は空き。

    例2

    →

    三の行はもう1三で揃っているので、5三の苔「2」のまわりに入れられる石は、二の行から1つと四の行から1つの最大2つ。これが苔の数と同じなので、どちらの行も石を苔のまわりに入れるしかなく、二・四の行の残りは空き。

    苔のまわりに入れられる石の最大数を、行・列の残りや「2×2には1つまで」から数える。苔の数と同じなら、置き場所が決まる。

    いくつかの行が、同じ数の列を取り合う六間八間

    例1

    →

    二と四の行の候補は、どちらも2か1の列。2行の石2つで2・1の列を使い切る（赤い列）ので、ほかの行の2・1の列は空き。

    例2

    →

    一・三・五の行の候補は、どれも6・4・2の列の中。3つの行の石3つで6・4・2の列を使い切る（赤い列）ので、二・四・六の行の6・4・2の列は空き。

    行の候補が、行と同じ数の列に収まっていたら、その列はその行で使い切られる。行と列を入れ替えても同じ。

    解き方のコツ（十間・難しい）

    十間（石20）の「難しい」の盤面で使う形です。十間では行・列に石が2つ入るので、候補が何マス続きで、どう分かれているかから、その行の中だけでなく、隣の行・列や苔のまわりまで決まることがあります。石がまだ入っていない行・列の候補の並び方に注目してください。図は、形だけを取り出した簡単な例です。

    候補が5マス幅に収まる行は、2番目と4番目の上下が空き十間
    →

    三の行は残り2つで、候補は8三〜4三の5マス続き。8三〜6三に1つも入らないと、残りの5三・4三に2つ入って隣り合ってしまう。だから8三〜6三に必ず1つ、同じように6三〜4三にも必ず1つ入る。8三〜6三のどれにも隣り合う7二・7四と、6三〜4三のどれにも隣り合う5二・5四は、空き。

    候補が「8三・6三〜4三」や「8三・6三・4三」のように飛び飛びでも、5マス幅に収まっていれば同じ。

    片方に1つしか入らないなら、もう片方に必ず1つ十間

    例1

    →

    三の行は残り2つ。3三には1つしか入らないので、9三〜7三に必ず1つ入る。3マスのどれにも隣り合う8二・8四は空き。

    例2

    →

    2マス続きには石が1つまでなので、9三・8三に1つ、4三・3三に1つ。それぞれの上下の2マスは空き。

    必ず1つ入るマスが苔「1」のまわりに収まれば、苔の残りは空き十間
    →

    二の行の候補は8二〜4二の5マス続きなので、8二〜6二に必ず1つ入る（5マス幅の形）。この3マスは7三の苔のまわりに収まるので、苔の「1」はそれで使い切る。苔のまわりの残り、8三・6三・8四・7四・6四は空き（5三も5マス幅の形で空き）。

    4マス続きの端、2マス続きの組、「3マス続き＋離れた候補」の真ん中のマスの隣にある苔「1」でも同じ。5マス続きの真ん中の隣にある苔では決まらない。

    4マス続きの2番目の隣に苔「1」なら、反対の端が石十間
    →

    二の行の置き方は「8二と6二」「8二と5二」「7二と5二」の3通り。「8二と6二」は苔のまわりに2つ入るので使えない。残る2通りはどちらも5二が石、6二は空き。どちらでも苔のまわりに1つ入るので、苔のまわりの残りも空き。
