解くときのコツ（基本）

どの難しさでも使う、1つの行・列・苔だけを見れば決まる形です。「手引き多め」の盤面は、この形だけで最後まで解けます。図は、形だけを取り出した簡単な例です。

石のまわり8マスには、石を置けない六間八間十間
→
揃った行・列の残りは空き六間八間十間
→
揃った苔の残りは空き六間八間十間
→
行・列の残りのマスの数＝残りの石の数なら、全部石六間八間十間
→
苔の残りのマスの数＝残りの石の数なら、全部石六間八間十間
→
苔の数と「隣り合わない」決まり六間八間十間
→

3三・4四・3四は互いに隣り合うので、石は1つまで。もう1つは5二。

候補が3マス続きなら、両端に石十間
→

隣り合わずに石2つが入るのは、両端（8三・6三）だけ。

候補が2つの塊に分かれていたら、塊ごとに1つ十間
→

2マス続き（9三・8三）には石が1つまで。もう1つは3三。

苔の「4」は、四隅に石十間
→

隣り合わずに4つ置けるのは、四隅だけ。

苔の「3」で隅が1つ空きなら、対角の隅に石十間
→

置き方は「隅3つ」か「辺の真ん中1つ＋反対側の隅2つ」。5三が空きなら、どれも3五を使う。

解くときのコツ（手引き少なめ）

「手引き少なめ」の盤面は、1つの行・列・苔だけを見ても次の一手が決まらない場面があります。2つの手がかり（行と行、行と苔、苔と苔）の置き方の組み合わせを全部考え、どの組み合わせでも同じになるマスを確定するのが基本です。図はどれも実際の盤面から取っています。

2つの行が、同じ2列を取り合う六間八間
→

二と四の行の石は、どちらも2か1の列。この2列の石は2行で使い切るので、2六・1六は空き。

片方の置き方が、もう片方の置き場をつぶす六間八間十間
→

二の行の石は2二か1二。2三・1三はどちらとも隣り合うので、三の行の石は6三。

行の候補が、すべて苔のまわりに入っている六間八間十間
→

一の行の石（6一か5一）で5二の苔「1」が埋まるので、4二は空き。石20では、行と苔の残りの石の数が同じときに使えます。

苔の候補が、すべて1つの行に入っている六間八間十間
→

6五の苔「1」の石は六の行（6六か5六）に入るので、2六・1六は空き。石20では、行と苔の残りの石の数が同じときに使えます。

苔と苔の引き算六間八間十間
→

6三の「1」の候補は、すべて5三の「2」のまわり。「2」の残り1つは4二。

隣り合う2行・2列を、2×2のかたまりに分ける十間
→

2×2には石が1つまで。2列の5つのかたまりに石4つなので、空のかたまり（三〜四）以外に1つずつ。五〜六は候補が8六だけ。

候補が2〜3マスしかない行・列・苔を探し、隣の行や重なる苔と組み合わせてみてください。印をこまめに付けると候補が見えやすくなります。
